# Ассемблер (tools/asm.py)

Двухпроходный ассемблер на Python 3 для процессора из `docs/ISA.md`. Читает текстовую программу
и создаёт образы памяти, которые загружаются в симуляторе через `$readmemb` / `$readmemh`.

## Запуск

```bash
python3 tools/asm.py sw/sort.asm            # -> sw/sort.rom.mem, sw/sort.ram.mem, sw/sort.lst
python3 tools/asm.py sw/sort.asm --hex      # те же файлы, но в hex (для $readmemh)
python3 tools/asm.py prog.asm --rom out_rom.mem --ram out_ram.mem --list out.lst
```

| Файл | Содержимое |
|---|---|
| `*.rom.mem` | образ памяти команд (секция `.text`) |
| `*.ram.mem` | образ памяти данных (секция `.data`), создаётся, только если данные есть |
| `*.lst` | листинг: адрес, слово (hex и двоичное с разбивкой на поля), исходная строка, таблица символов |

Формат `.mem`: одно 16-битное слово в строке, поля команды разделены `_`, после `//` комментарий с адресом и
исходной строкой. При разрывах адресов (директива `.org`) ставится метка `@адрес` (hex). Незаполненные ячейки ROM
в процессоре содержат `HLT`, RAM — нули.

## Синтаксис

- Одна команда или директива в строке. Комментарий начинается с `;` или `//`.
- Метка: `имя:` в начале строки (можно отдельной строкой, можно несколько подряд). Имена чувствительны к регистру,
  имена команд и регистров как метки использовать нельзя.
- Команды и регистры (`R0`–`R7`) не чувствительны к регистру.
- Операнды разделяются запятыми. Операнд памяти: `[Rs]`, `[Rs+выражение]`, `[Rs-выражение]`.
- Числа: `123`, `0x1F`, `0b1010`; допускается `_` внутри (`0xFF_00`).

### Выражения
Везде, где нужна константа или адрес, можно писать выражение: метки, символы `.equ`, числа и операции
`+ - * / %`, `<< >>`, `& | ^`, унарные `- + ~`, скобки, функции `lo(x)` (младший байт) и `hi(x)` (старший байт).
Приоритеты как в языке C.

### Директивы

| Директива | Действие |
|---|---|
| `.text` | переключиться на секцию команд (ROM, по умолчанию) |
| `.data` | переключиться на секцию данных (RAM) |
| `.org выражение` | установить адрес в текущей секции |
| `.equ ИМЯ, выражение` | определить константу (выражение должно использовать уже известные символы) |
| `.word в1, в2, ...` | разместить 16-битные слова (допустимо −32768…65535) |
| `.space N` | зарезервировать N нулевых слов |

Метка в секции `.data` получает адрес в RAM, в секции `.text` — адрес в ROM.

## Команды

Мнемоники и коды операций полностью совпадают с `docs/ISA.md`:

| Операнды | Команды |
|---|---|
| `rd, rs, rt` | `ADD SUB AND OR XOR` |
| `rd, rs` | `NOT SHL SHR BIN2BCD` |
| `rs, rt` | `CMP` |
| `rd, rs, imm5` | `ADDI` (imm5: −16…15) |
| `rd, imm8` | `LDI LHI` (imm8: 0…255) |
| `rd, [rs+imm5]` | `LOAD STORE` |
| `адрес` | `JUMP` (0…2047), `BEQ BNE BLO BHS` (в ассемблере указывается метка/адрес цели, смещение считается автоматически, диапазон ±1024) |
| `rs` | `JR` |
| — | `HLT` |

## Псевдокоманды

| Псевдокоманда | Раскрывается в | Слов |
|---|---|---|
| `NOP` | `ADD R0, R0, R0` (слово `0x0000`) | 1 |
| `MOV rd, rs` | `ADD rd, rs, R0` (**меняет флаги Z, C**) | 1 |
| `LI rd, выражение` | `LDI rd, v` если значение известно на первом проходе и 0…255, иначе `LDI rd, lo(v)` + `LHI rd, hi(v)` | 1 или 2 |
| `CALL метка` | `LDI R7, lo(ret)` + `LHI R7, hi(ret)` + `JUMP метка`, где `ret` — адрес следующей за `CALL` команды | 3 |
| `RET` | `JR R7` | 1 |

Вложенные вызовы невозможны (нет стека): `R7` при необходимости сохраняется в RAM вручную. Флаги при `CALL` и `RET`
не меняются.

## Алгоритм

1. **Проход 1.** Строки читаются по порядку. Убираются комментарии, определяются метки (им присваивается текущий адрес),
   выполняются `.org`, `.equ`, `.text`, `.data`, учитывается размер каждой команды и данных
   (команда — 1 слово, `CALL` — 3, `LI` — 1 или 2, `.word` — по числу значений). Так метки, используемые «вперёд»,
   получают адреса ещё до кодирования.
2. **Проход 2.** Для каждой команды вычисляются выражения, проверяются диапазоны, команда кодируется в 16-битное слово
   по форматам из ISA (R, I, L, J). Проверяется, что адреса укладываются в память и ничего не перекрывается.
3. Результат записывается в `.rom.mem`, `.ram.mem` и `.lst`.

## Ошибки

Ассемблер останавливается на первой ошибке, указывает файл, номер строки и саму строку, например:

```
sw/x.asm:7: ошибка: константа 300 вне диапазона 0..255 (imm8)
    LDI R1, 300
```

Проверяются: неизвестная команда, неверный регистр, число операндов, диапазоны `imm5`/`imm8`, неизвестный символ,
повторное определение метки, слишком далёкое ветвление, выход за границы памяти, пересечение областей,
команды вне секции `.text`.

